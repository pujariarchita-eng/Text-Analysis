# Text Analysis using Python

## Project Overview

This project was developed as part of the Veda Technology internship task. It demonstrates basic text-processing techniques using Python and Jupyter Notebook.

The program analyzes a sample text and calculates the number of words, characters, vowels, and repeated words.

## Objective

The main objectives of this project are:

- Count the number of words in a given text
- Count the number of characters
- Count the number of vowels
- Identify repeated words
- Practice basic text-processing techniques
- Understand the fundamentals of Natural Language Processing (NLP)

## Technologies Used

- Python
- Jupyter Notebook
- Python collections.Counter

## Project Features

### 1. Word Count
Counts the total number of words in the given text.

### 2. Character Count
Calculates the total number of characters in the text.

### 3. Vowel Count
Counts the occurrences of vowels (a, e, i, o, u).

### 4. Repeated Word Analysis
Uses Python's Counter to identify words that occur more than once.

- *Number of characters:* 206
- *Number of vowels:* 69

## How to Run

1. Install Python on your computer.
2. Install Jupyter Notebook if it is not already installed.
3. Open Jupyter Notebook.
4. Open Text Analysis.ipynb.
5. Run the cells using *Shift + Enter*.
6. View the text-analysis results in the notebook.
